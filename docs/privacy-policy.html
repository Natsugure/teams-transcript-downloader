Privacy Policy

Last Updated: December 29, 2025

TL;DR: This extension does not collect, store, or transmit any user data. Everything happens locally in your browser.

1. Information Collection and Use

Teams Transcript Downloader does not collect, store, or transmit any personal information or user data. The extension operates entirely within your browser.

2. How the Extension Works

The extension performs the following actions locally in your browser:

  • Detects when you visit a Microsoft Teams recording page on SharePoint
  • Checks if a transcript is available for the recording
  • Downloads the transcript file when you click the extension icon

All of these operations are performed locally. No data is sent to any external servers or third parties.

3. Permissions Used

The extension requires the following permissions to function:

activeTab

This permission allows the extension to interact with the currently active tab when you click the extension icon. It is only activated when you explicitly click the icon.

Host Permission (https://*.sharepoint.com/*)

This permission is required to access Microsoft Teams recording pages hosted on SharePoint domains. The extension only activates on pages matching the pattern *.sharepoint.com/*/stream.aspx*.

4. Data Storage

The extension does not store any data persistently. Temporary data used during operation (such as transcript availability status) is stored only in memory and is cleared when you close the tab or browser.

5. Third-Party Services

This extension does not use any third-party services, analytics, or tracking tools.

6. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated "Last Updated" date.

7. Contact

If you have any questions about this Privacy Policy, please contact us through our GitHub repository.
